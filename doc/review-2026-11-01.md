# Functional review and portrait readiness — 2026-11-01

Scope: all five screens, starting from main `894204f` after M8. This is a source and
automated integration review with fixes, not human educator, assistive-technology, or
physical-device release sign-off. Runtime: WSL Ubuntu, Node 26.13.0; Windows Chrome
for actual WebGPU presentation, plus WSL Chromium for general fuzz.

## Physics paths checked

- Orbitals: radial normalization, spherical-harmonic phase convention, real/complex
  transformations, expectation values, nodes, charge scaling, probability sampling,
  and display-unit conversion. Independent closed forms and quadrature remain in the tests.
- Superposition: duplicate-state normalization/cancellation, relative dynamical phases,
  dipole selection rules, radial position matrix elements, r/z expectations and playback.
- Angular Momentum: orbital/coupled vector magnitudes, projection, L+S closure,
  uncertainty bounds and spin-traced angular weights.
- Zeeman: spinless triplets, Dirac binding energies, Landé factors with g_s=2,
  allowed transitions, polarization filtering, weak-field cap and wavelength conversion.
- Oscillator: Cartesian Hermite and spherical Laguerre states, degeneracies, complete
  basis unitarity, overlap conjugation and CPU/GPU field agreement through N=4.

## Confirmed findings and changes

1. **The uniform isosurface box missed compact components of mixed-scale states.**
   A normalized equal-weight 1s + 5g state gave captured probability **0.8367** at the
   box size needed for 5g. Rescaling that grid to its own total masked the loss and
   biased the nominal enclosed fraction. Runtime surfaces now use 128 square-root
   radial bins, 48 Gauss-Legendre polar nodes and 64 azimuth samples, with physical
   cell weights. The regression checks captured norm against unity and checks a 1s
   surface against its analytic cumulative probability. Fractions remain numerical
   approximations of captured probability, not certified exact enclosure.
2. **Surface construction and burn-in monopolized an animation callback.**
   The high oscillator surface switch took about 189 ms in the desktop baseline;
   dipole/sp3 dot initialization took about 68/100 ms. Sampling and weighted-threshold
   search now yield on a 4 ms budget. Dot burn-in preserves the exact seeded proposal
   and acceptance sequence across batches. Typical isolated switch calls measured
   about 5 ms for surfaces and 8 ms for dots after the change. These are observations,
   not worst-case execution guarantees. Pending surfaces show volume plus a status;
   unfinished dot clouds show a sampling status. Paused edits supersede old requests.
3. **Oscillator selection rebuilt every overlap-table node.**
   The view now allocates its finite set of cells once during loading. Shell changes
   update their data; row/column changes move only the outlines. Cached overlap
   numbers contain no view listeners. Cartesian normalization uses separable 1D
   maxima; spherical normalization factors radial/angular maxima and reuses radial data.
4. **Portrait mode made controls unreadably small.**
   All five screens now reflow into a clipped vertical column at a 400-unit design
   width. Coefficient rows wrap while keeping the controls live. A scroll bar,
   wheel input and swipes outside controls navigate it. PDOM focus reveals controls,
   and rotating restores the desktop composition. Portrait navigation and a compact
   display-settings dialog avoid reliance on the small framework footer.
5. **Invalid time steps could poison the clocks.**
   Animated screen models and the composed timer now ignore nonfinite/nonpositive
   durations. Tests check that subsequent valid steps still advance normally.

## Evidence and practical limits

Browser regressions cover all five portrait layouts, focus-to-reset reveal, touch
scrolling, repeated rotation, screen switching and settings. Chromium's native
accessibility tree exposes the updated mean radius; this checks the platform tree,
not only the hidden PDOM. Seeded pointer fuzz also runs with randomized listener order.

In one 390×844 emulated viewport with CPU throttled 4×, the N=4 oscillator surface
workload averaged about 56 requestAnimationFrame callbacks per second over 120 frames,
with a roughly 20 ms 95th-percentile interval. Work was still pending at the end of
that observation. The whole cold shell gesture improved from about 257 ms to 40 ms
after table reuse; this includes synchronous control updates and is distinct from
the surface work slice. A slower CPU can take several seconds to finish a surface
while the controls remain usable. GPU throughput is not throttled by this experiment.

During animated superposition playback, one surface snapshot finishes before a
new snapshot is requested, with a minimum 250 ms refresh interval. The threshold can
lag the current phase. Pausing requests the exact current state and settles it;
dot updates similarly use finite sweeps at sampled times. These are visual approximations.
